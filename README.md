# Aryan Mridha — Portfolio

A responsive React portfolio built with Vite, Framer Motion, and Lucide React. The visual direction pairs a name-led split hero, a teal orbital code illustration, and deep-blue project and skills sections.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Import this repository into Vercel and use the default Vite settings. The site is static; the production output is generated in `dist/`.

The résumé PDF is served from `public/Aryan-Mridha-Resume.pdf`. Project summaries are based on Aryan's résumé and available project repositories. Only the Showroom and AI Chatbot cards link to repositories confirmed from the local project remotes.
